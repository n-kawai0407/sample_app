# 発信ネタ100本（現役エンジニア視点）

Phase 1（認知・ブランド構築）用のネタ集。
**「試験では問われないが現場で必須」「資格→実務の橋渡し」** を軸に、
あなたの実務経験でしか書けない切り口を優先しています。

## 使い方（1ネタ4媒体の使い回し）

1ネタを **Zenn記事（詳しく）→ X投稿に分割（要点）→ note（体験談寄り）→ 後でeBookの1節** に展開。
1回の労力で4媒体をカバーするのが、副業×週末で続けるコツです。

優先度の目安: ⭐ = バズりやすい/差別化が効く / 🔰 = 初心者向け（CLF/SAA集客） / 💼 = 実務直結（あなたの強み）

## ネタ出しのフレームワーク（枯れたら使う）

ネタが尽きたら以下の掛け合わせで無限に生成できます。

```
[AWSサービス名] × [切り口]
切り口: 試験に出ないが必須 / 現場の使い方 / よくある事故 /
        選定基準 / コスト / トラブル診断 / 設計判断 / 学習法
```

例: 「Lambda × コスト」「DynamoDB × よくある事故」「VPC × 設計判断」

## 投稿カレンダーの型（週末完結）

- **土曜**: Zenn記事1本を執筆（A〜Eカテゴリから1つ）
- **日曜**: その記事をX用に3〜5投稿へ分割予約
- **平日**: スマホでネタメモ＆Xで軽い投稿（隙間時間のみ）
