# AWS認定資格 教材・収益化プロジェクト

現役エンジニアの実務知見を活かし、AWS認定資格の教材を作って収益化するためのコンテンツ資産集です。

## 戦略サマリー

**「副業・週末 × 現役エンジニア × ブランド構築優先」** に最適化した
**コンテンツマーケ型**（発信 → 信頼 → 収益化）で進めます。

```
【Phase 1】発信・認知       →  【Phase 2】信頼・リスト       →  【Phase 3】収益化
無料コンテンツで露出           メルマガ/コミュニティで囲い込み    教材・サブスクで回収
(週末に量産・ストック型)        (関係構築)                       (作り切り型から)
```

- **最大の武器**: 現役エンジニアの「現場で本当に使える」視点（資格対策どまりの競合に勝つ）
- **初期商品形態**: テキスト中心（時間制約に合う、一度作れば再販可能）
- **優先資格**: CLF（集客フロント）→ SAA（主力）→ SAP/DOP（高単価バック）

## 使い方

1. **01** のネタリストから週末に記事を量産し、X/Zennで発信を習慣化する
2. **03** のロードマップをPDF化し、メルマガ/LINE登録の特典として無料配布する
3. リストが100件を超えたら **04** の問題集をオリジナル制作し有料リリースする
4. **02** は最初の1本。「現場視点」のトーンを掴むためのテンプレートとして使う

## 注意点（コンプライアンス）

- **AWS商標ガイドライン遵守**: 「AWS公式」と誤認させる表現はNG。ロゴ使用に注意
- **公式問題の転載は絶対NG**: 問題集は必ずオリジナル作成
- **勤務先の副業規定・競業避止の確認**: 現役エンジニアは就業規則を要チェック
